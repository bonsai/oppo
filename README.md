# oppo

**oppo / Dial P2** — 人と人の経験・記憶を集め、証拠とともに再接続するリサーチプロジェクト。

## Research seed

最初のテーマは、1990年代を中心とした「ダイヤルQ2の思い出」。

- `research/dial-q2/evidence.md` — 検証可能な一次・公的資料
- `research/dial-q2/memory.md` — 思い出・回想を収集するためのRAGメモ

## Dial P2

`P2 = Person ↔ Person` を仮説的な意味として、Q2時代の「電話で誰か／何かにつながる」経験を、現代の記憶・証言リサーチへ引き継ぐ。

## Evidence policy

事実・同時代資料・本人回想・伝聞を分離する。URL、発行主体、日付、引用対象を記録し、RAGでは出典を失わない。
